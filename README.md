# PRDA SI 5 — Hy2Car

Projet de recherche / développement (ENSEM) — optimisation par cosimulation d’un véhicule hybride.

**Élève :** Hafsa Mehdaoui  
**Laboratoire :** LORIA  
**Encadrants :** Vincent Chevrier, Diego Alejandro Vega  
**Période :** octobre 2026 – février 2027

## Sujet

Véhicule hybride pile à combustible (10 kW) + supercondensateurs (21 kW).  
Travail autour de la cosimulation et de l’optimisation boîte noire (choix de sous-modèles comme variables de décision), sur des données de parcours réels.  
Outils prévus : Java, JSON, Git.
